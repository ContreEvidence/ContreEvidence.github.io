# Contre-Évidence — Audit de couverture des situations

Mise à jour : 16 août 2026

## Pourquoi cet audit existe

Un dossier peut être profond **dans le cas qu’il traite** et rester mauvais comme page d’acquisition si sa promesse attire plusieurs situations voisines qu’il ne reconnaît pas.

Exemple : « Vous avez acheté à deux et vous vous séparez » peut attirer une indivision directe, une SCI, un couple marié, des partenaires de PACS, une tontine, un seul propriétaire avec deux financeurs ou plusieurs structures de prêt. Une excellente page sur l’indivision directe n’est donc pas une excellente réponse à cette promesse large si elle laisse les autres cas sortir silencieusement.

L’audit des angles morts existant demande :

> **Dans ce cas, quel raisonnement manque ?**

Le présent audit demande une autre chose :

> **Quels cas raisonnablement attirés par la promesse ne sont même pas reconnus, traités ou routés ?**

Les deux audits sont complémentaires.

## Règle fondamentale

> **Une promesse large exige une profondeur en éventail.**

La page n’a pas besoin de tout expliquer. Elle doit cependant faire l’une des quatre choses pour chaque variante matérielle :

- `TRAITEE` — la variante est suffisamment analysée sur la page ;
- `ROUTEE` — la variante est reconnue et envoyée vers une ressource adaptée ;
- `HORS_PERIMETRE_EXPLICITE` — le lecteur comprend immédiatement que son cas diffère et sait quoi vérifier ensuite ;
- `MANQUANTE` — la variante n’est pas reconnue : le visiteur peut repartir sans que le site apprenne pourquoi.

`MANQUANTE` est l’état à réduire avant une campagne d’acquisition.

## Ce que l’on audite

### 1. La promesse réelle

Lire ensemble :

- le titre SEO ;
- le H1 ;
- la meta description ;
- le chapeau ;
- les premières phrases ;
- l’accroche prévue sur les réseaux si elle existe.

La promesse réelle peut être plus large que le titre technique de la page.

### 2. Les variantes raisonnables de situation

Tester, lorsque pertinent :

1. **architecture juridique / propriété** — direct, indivision, société, SCI, mariage, PACS, concubinage, tontine, propriétaire unique ;
2. **structure du foyer** — seul, couple, enfants, héritiers, plusieurs associés ;
3. **statut professionnel** — CDI, CDD, contractuel public, indépendant, chômeur, retraité, reprise récente ;
4. **structure du revenu** — stable, variable, multi-revenus, aides, rente, revenus locatifs ;
5. **financement** — cash, crédit seul, co-emprunt, dette de société, garantie personnelle, apport inégal ;
6. **fiscalité / régime** — IR, IS, micro, réel, nu, meublé ou autre régime qui change la mécanique ;
7. **phase temporelle** — avant engagement, pendant, sortie, renouvellement, décès, séparation, changement de statut ;
8. **objectif réel** — acheter, habiter, produire un revenu, transmettre, récupérer du cash, préserver la mobilité ;
9. **géographie / règles locales** — lorsque le droit ou le marché varie localement ;
10. **niveau de contrainte** — situation saine, fragile, impayé, dette, incapacité, conflit, urgence ;
11. **acteur / gatekeeper** — autre banque, employeur, administration, associé, héritier, bailleur, locataire ;
12. **niveau de sophistication** — débutant, personne déjà engagée, patrimoine mature, entreprise déjà active.

Une dimension n’est pertinente que si elle peut changer le droit, le calcul, le risque, la séquence ou l’option de sortie.

## Largeur de promesse

### Promesse étroite

Exemple : « Indivision immobilière : qui touche les loyers ? »

Le lecteur est déjà qualifié. La page n’a pas à devenir un traité de SCI, de régime matrimonial ou de tontine. Elle doit seulement éviter de laisser croire que ses règles valent pour toutes les structures voisines.

### Promesse large

Exemple : « Vous avez acheté à deux et vous vous séparez : que devient le logement ? »

Elle doit reconnaître les architectures principales avant de lancer un calcul ou une recommandation.

### Promesse très large

Exemple : « Comment investir dans l’immobilier ? »

Elle exige soit une page-carrefour, soit un aiguillage explicite. Une page unique qui suppose sans le dire « location nue détenue en direct par une personne physique » est insuffisante comme destination d’acquisition.

## Score heuristique

Le score automatique n’est pas un jugement éditorial. Il sert à trouver les pages à relire.

On peut raisonner ainsi :

> **Risque de couverture = largeur de la promesse × divergence entre variantes × importance de la variante × absence de traitement/routage.**

Le système ne prétend pas connaître une probabilité réelle à partir de mots-clés. Les volumes de trafic, données de recherche et comportements utilisateurs devront ensuite prioriser les variantes observées.

## Familles prioritaires

### Couple / logement / séparation

Variantes critiques :

- indivision directe ;
- SCI ;
- mariage ;
- PACS ;
- concubinage ;
- tontine ;
- un seul propriétaire mais plusieurs financeurs ;
- co-emprunteurs / dette distincte de la propriété ;
- vente, maintien, location, rachat ou sortie progressive.

### Achat immobilier / crédit

Variantes critiques :

- achat seul / à deux ;
- CDI / CDD / public / indépendant / reprise récente ;
- résidence principale / locatif ;
- apport élevé / faible ;
- dette déjà existante ;
- mobilité professionnelle ;
- achat avant ou après un changement de situation.

### Investissement locatif

Variantes critiques :

- détention directe / SCI ;
- location nue / meublée / courte durée ;
- IR / IS lorsque pertinent ;
- gestion directe / déléguée ;
- crédit / cash ;
- investisseur débutant / patrimoine déjà concentré.

### Transmission / succession

Variantes critiques :

- couple marié / PACS / concubinage ;
- enfants / absence d’enfants / famille recomposée ;
- immobilier direct / SCI ;
- donation / succession / assurance-vie ;
- actifs liquides / bien difficile à partager ;
- égalité souhaitée / avantage d’un bénéficiaire.

### Reconversion / emploi

Variantes critiques :

- salarié / demandeur d’emploi / agent public / indépendant ;
- CDI / CDD ;
- santé ou inaptitude ;
- diplôme / sans diplôme ;
- débutant / senior ;
- maintien de revenu nécessaire ou non ;
- changement de métier / fonction / secteur uniquement.

### Entrepreneuriat

Variantes critiques :

- activité principale / complémentaire ;
- micro / EI / société ;
- activité réglementée / non réglementée ;
- chômage indemnisé / salarié / sans filet ;
- TVA / non TVA ;
- besoin de financement / activité légère ;
- solo / associés.

### Budget / dette

Variantes critiques :

- déficit temporaire / structurel ;
- revenu stable / instable ;
- propriétaire / locataire ;
- solo / couple ;
- dette ordinaire / situation de surendettement ;
- marge d’économie réelle / charges déjà incompressibles.

### Travailler moins / qualité de vie

Variantes critiques :

- salarié privé / public / indépendant ;
- 80 % / quatre jours / télétravail / changement de poste ;
- seul / couple ;
- patrimoine disponible / aucune marge ;
- impact retraite et protection sociale ;
- temps réellement libéré / charge simplement comprimée.

## Gate avant publication d’acquisition

Aucune publication destinée à amener une audience froide vers une page ne doit être considérée prête avant d’avoir répondu à quatre questions :

1. **Qui l’accroche peut-elle raisonnablement attirer ?**
2. **Quelles variantes changent matériellement la réponse ?**
3. **Pour chacune, le site traite-t-il, route-t-il ou exclut-il explicitement le cas ?**
4. **Si le visiteur ne correspond pas au cas central, pouvons-nous apprendre ce qu’il cherchait au lieu de voir seulement un abandon ?**

Une campagne peut être lancée avec des variantes non traitées si elles sont explicitement identifiées et routées vers un aiguillage ou un diagnostic. Elle ne doit pas être lancée en prétendant offrir une réponse universelle alors que le contenu suppose silencieusement un seul cas.

## Ce que cet audit ne doit pas produire

- un paragraphe générique « cela dépend de votre situation » sur toutes les pages ;
- des pages encyclopédiques qui répondent mal à tout ;
- une inflation de contenus uniquement pour couvrir des mots-clés ;
- un faux score de complétude ;
- la confusion entre mentionner une variante et la traiter ;
- une obligation de dupliquer le même contenu sur plusieurs pages.

Le meilleur correctif est souvent un **aiguillage précis**, pas une réécriture complète.

## Boucle d’apprentissage cible

> **publication / recherche → page d’entrée → variante de situation reconnue → ressource adaptée → résultat → prochaine décision → mesure du parcours**

Si une audience arrive mais que sa variante n’existe pas dans cette boucle, l’absence de conversion doit être considérée comme une information produit à récupérer, pas comme un simple échec de communication.
